# Revisão — PR #1 `feat/export-camadas` (issue #1)

**Veredito: aprovado para merge**, com dois ajustes pequenos (podem ir no mesmo PR ou num commit seguinte).

## O que está bom
- `ingest/export.py`: leitura em *stream* Arrow (`pyogrio.raw.open_arrow`) com lotes → Parquet e GPKG; GeoParquet
  1.0 com metadados `geo` (WKB, CRS 4674, bbox, tipos) calculados por lote; erro claro para camada inexistente;
  Parquet parcial removido em caso de falha. Exportação real: SSDMT 1,0 M feições em ~4 s, UCBT_tab 5,0 M em ~23 s.
- `cli.py` (typer) com `--gdb/--layers/--out/--gpkg/--batch-size`, saída rich, exit 1 sem traceback.
- 15 testes sobre fixture sintética (`bdgd_mini.gpkg` + `gerar_fixture.py`, com teste que garante sincronia entre
  os dois), incluindo CLI. README documenta o comando. Commits em Conventional Commits, uv respeitado.

## Ajustes pedidos
1. **Descobertas sobre a BDGD Light 2025 devem virar documentação de referência**, não só nota no README:
   criar `docs/bdgd-light-2025.md` com: CTMT é tabela; não há `UCBT/UCMT/UGBT/UGMT` geográficas (só `*_tab`);
   subestação = `UNTRAT` + coluna `SUB`; `PAC` numerado por alimentador (`<CTMT>_MT_<n>`), logo interligações
   entre alimentadores **não** compartilham PAC (ver `docs/escopo-alimentadores.md`); `TEN_NOM` 46 = 13,8 kV e
   67 = 25 kV (conferir na tabela de domínio do Manual da BDGD); tabela de códigos `TIP_UNID` de `UNSEMT`
   (19, 22, 16, 32, 29, 35, 27, 33, 20, 18, 17 — mapear pelo Manual, ex.: religador, seccionalizador, fusível,
   faca…). Linkar no README.
2. `export.py` importa `numpy`, `pyproj`, `shapely` diretamente: declarar em `pyproject.toml` (`numpy>=1.26`,
   `pyproj>=3.6`; shapely já está) para não depender de dependência transitiva. Rodar `uv lock`.
