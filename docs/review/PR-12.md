# Revisão — PR #43 `feat/mcp-server` (issue #32)

**Veredito: aprovado, com os três pontos de segurança que eu tinha marcado atendidos:** (1) `set_switch` sem token
válido é recusado (`compare_digest`, validade 30 min, proposta rejeitada/executada/expirada); (2) `approve`/`reject`
**não são ferramentas do modelo** — só CLI humana ou rota HTTP; (3) tokens mascarados na auditoria (`sha256:<12>`,
recursivo, hash do resultado sobre o mascarado). Além disso: sequência forçada abrir-fronteira → religador → NA
(nunca fechar anel sobre a falta), um passo por chamada; "visão de plano" com religador fechado para o raciocínio
após `inject_fault` — bug real do smoke resolvido de forma limpa. Domínio (`SessaoCOD`) independente do SDK, com
camada de compatibilidade mcp 1.x/2.x descoberta no CI. 200 testes.
